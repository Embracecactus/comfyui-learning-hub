## 系统手册包含什么

`ComfyUI-系统学习手册/` 按学习顺序拆成 9 章，并提供三层节点资料：

1. “如何读懂节点”讲通用方法。
2. “基础核心节点逐项详解”详细解释 102 个高频节点/节点组。
3. “全部内置节点索引”从当前 ComfyUI 0.33.0 源码生成，覆盖 639 个非 API 内置节点的输入和输出定义。

`images/` 和 `examples/` 继续作为本目录所有新手文档的共享图片与工作流资源。
