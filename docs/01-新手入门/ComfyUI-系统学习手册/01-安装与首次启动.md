# 01｜安装与首次启动

本章目标只有两个：打开 ComfyUI，以及知道模型应该放在哪里。还不需要理解采样器。

## 1. 先选安装方式

| 你的情况 | 推荐方式 | 原因 |
|---|---|---|
| Windows + NVIDIA 显卡，第一次安装 | Desktop 桌面版 | 自动管理 Python 和依赖，操作最少 |
| Windows，想解压即用或跟随最新代码 | Portable 便携版 | 自带 Python，便于整体移动和备份 |
| Linux / 有开发经验 / 需要精确控制环境 | 源码版 | 方便更新、调试和开发节点 |
| Apple Silicon Mac | Desktop 或源码版 | 使用 MPS；模型兼容性和速度需实际验证 |
| 没有独立显卡 | 云端 GPU 或 Comfy Cloud | CPU 能启动，但生成通常非常慢 |

官方当前将 Desktop 作为 Windows 新手的推荐安装方式。Desktop 使用稳定版，便携版和源码版通常更快获得新功能。

## 2. Windows Desktop 安装

1. 打开 [ComfyUI Windows Desktop 官方安装指南](https://docs.comfy.org/zh/installation/desktop/windows)。
2. 下载官方安装包并运行。
3. GPU 选择页选 `NVIDIA`。只有明确需要调试时才选 CPU 模式。
4. 安装位置选择空间充足的 SSD，新建一个空目录。
5. 等待 Python、PyTorch 和依赖安装完成。
6. 启动后能看到画布、左侧栏和右上角运行按钮，即安装成功。

注意：Desktop 管理的程序资源目录会在更新时被覆盖。模型、工作流和自定义节点应放到安装向导指定的数据目录，不要随意修改 `resource/ComfyUI`。

## 3. Windows Portable 安装

### 3.1 下载前先确认电脑是否支持

Portable 已经包含独立 Python 和 PyTorch CUDA 运行环境。通常不需要单独安装 CUDA Toolkit，也不要用 `nvcc --version` 决定下载哪个包。真正需要确认的是：**显卡型号**和**NVIDIA 驱动能够支持的最高 CUDA 版本**。

按 `Win + R`，输入 `cmd` 并回车，然后运行：

```powershell
nvidia-smi
```

正常情况下，顶部会显示类似：

```text
NVIDIA-SMI 580.xx    Driver Version: 580.xx    CUDA Version: 13.0
GPU Name: NVIDIA GeForce RTX 4060
```

重点看三项：

- `GPU Name`：显卡型号，例如 RTX 4060、GTX 1080。
- `Driver Version`：当前 NVIDIA 驱动版本。
- `CUDA Version`：当前驱动最高支持的 CUDA 版本，**不是**本机已安装的 CUDA Toolkit 版本。

想只查看显卡、驱动和显存，也可以运行：

```powershell
nvidia-smi --query-gpu=name,driver_version,memory.total --format=csv,noheader
```

### 3.2 根据检查结果选择下载包

| 检查结果 | 应选择的 Portable 包 |
|---|---|
| RTX 20/30/40/50 系列，且 `CUDA Version` 为 13.0 或更高 | NVIDIA CUDA 13.0 / Python 3.13 标准版 |
| GTX 16 系列（Turing），且驱动支持 CUDA 13 | 可用 CUDA 13.0 标准版；遇到兼容问题可改用 CUDA 12.6 版 |
| GTX 10 系列，例如 GTX 1050/1060/1070/1080 | NVIDIA CUDA 12.6 / Python 3.12 版 |
| GTX 9 系列及更早 NVIDIA 显卡 | CUDA 12.6 / Python 3.12 版；过老型号仍可能无法运行 |
| 新款 RTX，但 `CUDA Version` 只有 12.x | 先更新 NVIDIA 驱动；暂时无法更新时可使用 CUDA 12.6 版 |
| `nvidia-smi` 提示不是命令，但设备管理器里有 NVIDIA 显卡 | NVIDIA 驱动未正确安装，先从 NVIDIA 官网安装/更新驱动 |
| AMD 或 Intel 显卡 | 切换官方下载页的 AMD/Intel 标签，不能使用 NVIDIA CUDA 包 |
| 只有核显、没有受支持的独立显卡 | 可用 CPU 模式验证，但生成会非常慢，建议使用云端 GPU |

判断时显卡代际优先于 `nvidia-smi` 显示的数字。例如 GTX 1080 属于 Pascal 架构，即使新驱动显示最高支持 CUDA 13，也应选择 CUDA 12.6 包，因为 Pascal 的 Toolkit 支持停留在 CUDA 12.x。

CUDA 13.x 通常要求 R580 或更新的驱动。新驱动可以运行较旧 CUDA 构建的程序，因此不确定时选择 CUDA 12.6 包通常比在老显卡上强行使用 CUDA 13 更稳。具体支持情况以 [ComfyUI Portable 官方说明](https://docs.comfy.org/zh/installation/comfyui_portable_windows) 和 [NVIDIA CUDA 架构兼容矩阵](https://docs.nvidia.com/datacenter/tesla/drivers/cuda-toolkit-driver-and-architecture-matrix.html) 为准。

### 3.3 下载、解压和启动

1. 按 [官方便携版指南](https://docs.comfy.org/zh/installation/comfyui_portable_windows) 下载与显卡匹配的压缩包。
2. 使用 7-Zip 解压到短路径，例如 `D:\AI\ComfyUI_windows_portable`；不要直接放在压缩包里运行。
3. NVIDIA 用户双击 `run_nvidia_gpu.bat`；AMD/Intel 用户按下载包内说明启动。`run_cpu.bat` 只用于验证或特殊情况。
4. 终端出现 `To see the GUI go to: http://127.0.0.1:8188` 后，用浏览器打开该地址。

### 3.4 安装后确认 ComfyUI 真的在使用显卡

在 `ComfyUI_windows_portable` 根目录打开 CMD 或 PowerShell，运行：

```powershell
python_embeded\python.exe -c "import torch; print('PyTorch:', torch.__version__); print('PyTorch CUDA:', torch.version.cuda); print('CUDA 可用:', torch.cuda.is_available()); print('显卡:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else '未检测到')"
```

成功时应看到：

```text
CUDA 可用: True
显卡: NVIDIA GeForce RTX/GTX ...
```

如果显示 `CUDA 可用: False`，先检查是否下载错包、是否误运行了 `run_cpu.bat`，再更新 NVIDIA 驱动。若报 `no kernel image is available` 或提示 GPU 架构不受支持，老显卡应换用 CUDA 12.6 包。

便携版自带的 Python 位于 `python_embeded`。以后安装第三方节点依赖时必须使用这个 Python，不要误用系统 Python。

## 4. 源码版安装

源码版的 GPU 依赖与显卡平台有关。先按 [官方手动安装文档](https://docs.comfy.org/zh/installation/manual_install) 安装与你硬件匹配的 PyTorch，再安装 ComfyUI 依赖。

一个典型流程如下：

```bash
git clone https://github.com/Comfy-Org/ComfyUI.git
cd ComfyUI
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Windows PowerShell 激活虚拟环境：

```powershell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

不要无条件复制网上某条 PyTorch 安装命令。CUDA、ROCm、Intel、Apple Silicon 的安装方式不同，应以 PyTorch 与 ComfyUI 官方当期说明为准。

## 5. 启动地址和常用参数

默认本机地址：

```text
http://127.0.0.1:8188
```

常见启动方式：

```bash
# 只允许本机访问，默认也是这样
python main.py

# 更换端口
python main.py --port 8189

# 允许局域网访问；必须同时做好防火墙和访问控制
python main.py --listen 0.0.0.0

# 完全使用 CPU，能运行但通常很慢
python main.py --cpu
```

不要把 `--listen 0.0.0.0` 的实例直接暴露到公网。工作流、上传文件、模型信息和可能存在的第三方节点接口都不应默认公开。

## 6. 第一次启动后的检查

依次检查：

- 页面可以打开，画布能缩放和平移。
- 左侧 `Nodes` 能搜索到 `KSampler`。
- 右上角有 `Run` 或运行/入队按钮。
- 底部控制台没有持续出现红色 `IMPORT FAILED`。
- 设置 `Comfy → Locale` 可以切换中文；节点英文名仍建议保留用于检索。

如果没有模型，界面能打开也属正常。ComfyUI 程序和模型权重是分开的。

## 7. 模型目录

常用目录如下：

```text
ComfyUI/models/
├── checkpoints/       一体式 SD1.5、SDXL 等 checkpoint
├── diffusion_models/  分体式扩散模型 / UNet / DiT
├── text_encoders/     文本编码器
├── clip/              部分工作流使用的 CLIP/T5 文本编码器目录
├── vae/               独立 VAE
├── loras/             LoRA
├── controlnet/        ControlNet 模型
├── upscale_models/    ESRGAN、RealESRGAN 等放大模型
├── clip_vision/       CLIP Vision 模型
└── style_models/      风格模型
```

模型放错目录时，加载节点的下拉框不会显示它。放入新模型后按 `r` 刷新节点定义；仍无效时重启 ComfyUI。

## 8. 如何获得第一个模型

最省事的方法是使用官方模板：

1. 打开左侧 `Templates`。
2. 选择一个基础文生图模板。
3. 模板会检查缺失模型。
4. Desktop 可按提示下载；其他版本通常会打开下载页，并提示目标目录。

不要从来源不明的网盘下载可执行文件或安装器。模型优先选择 `.safetensors` 格式，并核对模型作者、许可、文件大小和校验信息。

## 9. 安装成功的验收标准

满足以下条件即可进入下一章：

- ComfyUI 能稳定启动并通过浏览器访问。
- 知道当前是 Desktop、Portable 还是源码版。
- 知道自己的数据目录和 `models/` 目录。
- 至少有一个模板需要的模型，或已明确准备通过模板下载。
- 能打开模板、节点库和控制台。
