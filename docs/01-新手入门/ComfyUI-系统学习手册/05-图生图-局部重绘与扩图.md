# 05｜图生图、局部重绘与扩图

## 1. 文生图和图生图只差在哪里

文生图给采样器的是 `Empty Latent Image`。图生图把真实图片编码成 latent：

```text
Load Image ─ IMAGE ─→ VAE Encode ─ LATENT ─→ KSampler(latent_image)
                           ↑
Load Checkpoint ─ VAE ────┘
```

其他模型、提示词、采样和解码链可以保持相似。KSampler 的 `denoise` 决定对原图改多少。

## 2. 基础图生图逐步搭建

1. 从基础文生图工作流复制一个新版本。
2. 删除或旁路 `Empty Latent Image`。
3. 添加 `Load Image`，上传输入图。
4. 添加 `VAE Encode`。
5. `Load Image.IMAGE → VAE Encode.pixels`。
6. `Load Checkpoint.VAE → VAE Encode.vae`。
7. `VAE Encode.LATENT → KSampler.latent_image`。
8. 把 KSampler `denoise` 先设为 `0.5`。
9. 固定 seed，分别测试 `0.25 / 0.5 / 0.75`。

常见直觉：

- 低 denoise：保留构图和颜色，只做轻微风格化或修饰。
- 中 denoise：主体轮廓还在，但材质、细节和局部结构会变化。
- 高 denoise：原图只提供粗略起点，结果可能明显改构图。

## 3. 尺寸为什么会变化

输入图经过 VAE 编码时可能受模型步长限制。若工作流还包含 Resize/Crop，长宽比也会改变。

建议明确选择一种策略：

- 保持长宽比，缩放到目标长边/短边。
- 中心裁剪到目标比例。
- 缩放并补边，避免裁掉内容。

不要在不知情时把人物竖图强行拉伸为正方形。

## 4. Mask 的白与黑

遮罩通常用 0～1 表示作用强度，但“白色是重绘还是保留”要看具体节点语义。对于常见的 `VAE Encode (for Inpainting)` / noise mask 流程，白色区域通常表示允许采样修改，黑色区域通常表示保留。

使用陌生遮罩节点时务必做一个极简测试：只画一小块纯白，观察到底修改哪里。不要仅凭 Photoshop 图层蒙版经验猜。

## 5. 局部重绘的核心链

常见路线 A：`VAE Encode (for Inpainting)`

```text
Load Image.IMAGE ───────────────→ pixels
Load Image.MASK / Mask Editor ─→ mask
Load Checkpoint.VAE ───────────→ vae
                       VAE Encode (for Inpainting)
                                 └→ LATENT（含 noise_mask）→ KSampler
```

常见路线 B：模型专用 `InpaintModelConditioning`

```text
positive + negative + VAE + pixels + mask
            ↓
InpaintModelConditioning
  ├→ positive
  ├→ negative
  └→ latent → KSampler
```

专用 inpaint 模型优先使用其官方模板，因为它可能需要额外通道或不同 conditioning。

## 6. 遮罩边缘

硬边遮罩容易形成接缝。常用处理：

- `Grow Mask`：向外扩一点，让模型有过渡空间。
- `Feather Mask`：羽化边缘，形成平滑过渡。
- `Blur` 类处理：软化遮罩，但要确认处理的是 MASK 而不是 IMAGE。

推荐顺序通常是先扩张，再轻微羽化。扩张和羽化数值取决于分辨率：1024 图上的 8 像素与 4096 图上的 8 像素效果不同。

## 7. Mask Editor

常见用法：

1. 在 `Load Image` 节点打开遮罩编辑器。
2. 用画笔标出要重绘的区域。
3. 保存遮罩并返回工作流。
4. 用 `Preview Mask` 或 `Mask to Image` 检查方向和边界。
5. 小尺寸、低步数试跑，再做最终质量。

如果 Load Image 的 `MASK` 全黑，常见原因是输入图没有 alpha 通道且你还没有绘制遮罩。

## 8. 扩图 Outpainting

扩图是在原图外增加画布并生成新增区域：

```text
Load Image
   ↓
Pad Image for Outpainting ─┬→ padded IMAGE → inpaint 编码
                           └→ MASK ─────────→ inpaint 编码
```

`left/top/right/bottom` 决定向哪边增加像素，`feathering` 控制新旧区域交界。提示词应描述完整扩展场景，而不只是写“扩图”。

## 9. 局部重绘排错表

| 现象 | 原因 | 处理 |
|---|---|---|
| 整张图都被改了 | mask 方向反、mask 全白或 denoise 太高 | Preview Mask，必要时 Invert Mask |
| 白块完全没变化 | mask 全黑、noise mask 未进入采样器 | 检查 mask 数据流和节点输出 |
| 边缘有明显接缝 | 遮罩太硬、上下文太少 | Grow + Feather，扩大重绘区 |
| 重绘内容与周围不一致 | 提示词、光线、模型或 denoise 不合适 | 描述完整场景，降低 denoise，多给边缘上下文 |
| 原图颜色整体漂移 | VAE 重编码或高 denoise | 使用匹配 VAE，缩小作用范围 |
| 人物被裁扁 | Resize 策略改变比例 | 改为保持比例、裁剪或补边 |

## 10. 练习

选一张 512～1024 像素图片：

1. 用图生图只改变画面风格。
2. 用遮罩只更换一个小物体。
3. 向右扩 25% 画布。
4. 为三个任务保存独立工作流，并写 Note 记录 denoise 和遮罩处理。
