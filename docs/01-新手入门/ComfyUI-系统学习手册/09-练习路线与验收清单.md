# 09｜练习路线与验收清单

这是一条 10 次练习路线。每次只增加一个新概念，完成后再进入下一项。

## 练习 1：加载官方模板

目标：成功生成一张图。

- 从 Templates 加载基础文生图。
- 按提示准备模型。
- 只改正向提示词并运行。
- 找到 `output/` 中的图片。

验收：能指出哪个节点加载模型、哪个节点采样、哪个节点保存。

## 练习 2：手搭基础文生图

目标：不依赖模板搭出 7 节点链。

- Load Checkpoint
- CLIP Text Encode × 2
- Empty Latent Image
- KSampler
- VAE Decode
- Save Image

验收：可以解释每条线的数据类型。

## 练习 3：控制变量

目标：理解 seed、steps、CFG。

- 固定 seed。
- 分别测试 steps 8/20/30。
- 分别测试 CFG 3/7/12。
- 做一个 2 × 3 对比表并写结论。

验收：知道“参数更大”为什么不等于“质量更高”。

## 练习 4：提示词结构

目标：用简洁提示词控制主体、构图和光线。

- 先只写主体和场景。
- 加镜头与构图。
- 再加光线和风格。
- 每一步固定 seed 保存结果。

验收：可以指出哪段提示词主要改变了什么。

## 练习 5：图生图

目标：理解 VAE Encode 和 denoise。

- Load Image → VAE Encode → KSampler。
- 固定 seed 测试 denoise 0.25/0.5/0.75。

验收：能够在“保留原图”和“重新创作”之间选择合适强度。

## 练习 6：局部重绘

目标：掌握 MASK。

- 在输入图上只遮住一个小物体。
- Preview Mask 确认黑白方向。
- Grow + Feather 处理边缘。
- 用 inpaint 链替换该物体。

验收：未遮罩区域基本保留，边缘没有明显硬接缝。

## 练习 7：LoRA

目标：正确判断兼容性并控制强度。

- 选择与基础模型架构相符的 LoRA。
- 先按作者参数运行。
- 固定 seed 比较强度 0/0.5/1.0。

验收：能区分模型不兼容、缺触发词和强度不足。

## 练习 8：ControlNet

目标：用结构条件控制生成。

- 准备匹配的预处理图和 ControlNet。
- 比较 strength 0/0.5/1.0。
- 比较 end_percent 0.5/1.0。

验收：能解释 strength 与生效区间分别控制什么。

## 练习 9：高清流程

目标：区分插值、超分和二次采样。

- 保存原始 512/1024 图。
- 做普通插值 2 倍。
- 做超分模型 2/4 倍。
- 做 latent upscale + 低 denoise 二次采样。

验收：能比较细节、伪影、耗时和显存，而不只看尺寸。

## 练习 10：读懂陌生工作流

目标：具备独立拆解能力。

拿一个官方新模型模板，完成：

1. 圈出所有加载器。
2. 标出 `MODEL/CLIP/VAE/CONDITIONING/LATENT/IMAGE` 主链。
3. 找到所有模型专用节点。
4. 找到最终输出节点。
5. 写出每个模块可单独验证的方法。

验收：即使不知道每个专用参数，也能说明数据从哪里来、到哪里去、哪一段负责什么。

## 最终能力清单

完成后，你应能独立做到：

- [ ] 选择正确安装方式并找到数据目录。
- [ ] 使用官方模板准备模型。
- [ ] 从空白画布搭基础文生图。
- [ ] 区分 MODEL、CLIP、VAE、CONDITIONING、LATENT、IMAGE、MASK。
- [ ] 用固定 seed 做可靠的参数对比。
- [ ] 搭建图生图、局部重绘和扩图。
- [ ] 正确接入一个兼容 LoRA。
- [ ] 理解 ControlNet 的控制图、模型和应用节点。
- [ ] 比较三种放大路线。
- [ ] 安全安装并排查自定义节点。
- [ ] 根据错误节点和完整日志定位问题。
- [ ] 整理、注释、版本化并分享工作流。
