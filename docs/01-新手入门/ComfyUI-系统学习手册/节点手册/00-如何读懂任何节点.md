# 如何读懂任何 ComfyUI 节点

节点数量会随 ComfyUI 版本、可选依赖和第三方插件变化。真正可迁移的能力不是背节点名，而是读懂“输入 → 处理 → 输出”。

## 1. 六步读节点法

遇到陌生节点时，按顺序问：

1. **它属于什么类别？** `model/loaders` 多半加载模型，`conditioning` 处理条件，`latent` 处理潜空间，`image` 处理像素。
2. **必需输入是什么？** 没接的必需端口会直接阻止运行。
3. **输入类型是什么？** `IMAGE`、`LATENT`、`MASK`、`MODEL` 不能因为名字相近就混接。
4. **参数改变什么？** 先找默认值、范围、单位和是否依模型变化。
5. **输出是什么？** 输出类型决定它能接到哪类下游。
6. **它是否模型专用、实验性或已弃用？** 专用节点应跟随官方模板，弃用节点不适合新建工作流。

## 2. 输入的三种形态

### 必需输入 required

必须有值或连线。报错 `Required input is missing` 时，错误信息通常会给出节点 ID 和输入名。

### 可选输入 optional

不连接时走节点默认行为。连接前先读说明，因为它可能改变输出语义，而不只是“增强效果”。

### 隐藏输入 hidden

由 ComfyUI 运行时自动提供，例如工作流元数据、prompt、节点 ID。一般不会在画布上让用户连接。

## 3. 参数控件与输入端口

节点内部的整数、浮点数、文本框和下拉框属于参数控件。许多控件可通过右键转换为输入端口，从而：

- 用 Primitive 统一控制多个节点。
- 用计算节点动态生成宽高、seed 或 strength。
- 从 API 或子图外部传入参数。

转换后如果端口没连接，执行数据里可能没有这个参数。遇到缺输入时检查控件是否被误转成端口。

## 4. 高频参数命名

| 参数 | 常见含义 | 注意 |
|---|---|---|
| `strength` | 影响强度 | 不同节点的有效范围和尺度不同 |
| `start_percent` / `end_percent` | 在采样时间轴的生效区间 | 0 是开始，1 是结束；不是图片位置 |
| `width` / `height` | 像素或目标尺寸 | 某些 latent/视频模型要求特定倍数 |
| `batch_size` | 同批处理数量 | 增大通常明显增加显存 |
| `seed` | 随机种子 | 固定环境和参数时用于复现/对比 |
| `steps` | 采样步数 | 更多不保证更好 |
| `cfg` / `guidance` | 条件引导强度 | 模型系列之间不能照搬 |
| `denoise` | 重绘/去噪强度 | 文生图常 1；图生图常低于 1 |
| `crop` | 缩放时裁剪策略 | `center` 可能裁掉边缘内容 |
| `method` / `mode` | 算法或处理模式 | 改动后固定输入做对比 |

## 5. 读端口名称，不只读类型

同一种类型也可能有不同语义。例如两个输入都是 `CONDITIONING`：

- `positive` 表示希望出现的条件。
- `negative` 表示希望抑制的条件。

两个输入都是 `IMAGE`：

- `destination` 可能是底图。
- `source` 可能是叠加图。

能连上只说明类型兼容，不代表语义正确。

## 6. 节点类别地图

| 类别前缀 | 主要职责 | 新手策略 |
|---|---|---|
| `model/loaders` | 加载模型组件 | 先核对模型目录、架构和精度 |
| `model/conditioning` | 构造/变换生成条件 | 弄清输出送 positive 还是 negative |
| `model/latent` | 创建、编码、解码或变换潜空间 | 不要和 IMAGE 混淆 |
| `model/sampling` | 噪声、调度、采样和引导 | 先使用普通 KSampler，再学拆分采样 |
| `model/patch` | 修改模型推理行为 | 只在模型模板或明确实验中使用 |
| `model/merging` | 合并或保存权重 | 会占大量内存/磁盘，先备份并核对许可 |
| `image` | 像素图输入、输出与处理 | 留意批次、通道、alpha 和尺寸 |
| `image/mask` | 遮罩生成与变换 | 先 Preview Mask 验证黑白方向 |
| `video` / `audio` | 时序媒体处理 | 留意帧率、时长、采样率和内存 |
| `3d` | 网格、点云、splat、纹理 | 留意坐标系、单位和文件格式 |
| `utilities` / `text` | 数字、逻辑、文本和辅助数据 | 常用于把固定工作流做成参数化工具 |
| `experimental` | 实验功能 | 版本变化快，保留可回退工作流 |

## 7. 从连线反推节点作用

如果没有文档，可用上下游反推：

```text
上游输出类型 ─→ [陌生节点] ─→ 下游输入类型
```

例如陌生节点接收 `MODEL` 并输出 `MODEL`，大概率是模型补丁或配置，不会直接生成图片；接收 `IMAGE` 输出 `MASK`，大概率是分割、颜色提取或阈值处理。

## 8. 如何使用节点内帮助

在当前前端中选中节点并打开节点帮助/文档。优先看：

- Description：用途。
- Inputs/Outputs：类型和语义。
- 参数默认值与限制。
- 示例工作流或模型链接。
- Deprecated/Experimental 标记。

节点内帮助与已安装代码版本更接近；在线文档适合补充背景。

## 9. 本手册全量索引如何读

[全部内置节点索引](03-全部内置节点索引.md) 中每项包含：

- 显示名和内部类名。
- 源码分类和模块。
- required/optional/hidden 输入。
- 输出类型和名称。
- 默认值、范围或部分枚举选项。
- 源码提供的官方英文说明。
- 基于类别给出的中文使用提醒。

索引用于回答“这个版本有没有这个节点、端口叫什么、能接什么”。模型专用节点的具体参数仍以对应官方模板和模型教程为准。

## 10. 两个安全原则

1. `Save Checkpoint`、训练、模型合并、写文件和 API 节点会产生文件、耗时、磁盘占用或外部请求；运行他人工作流前先检查输出节点。
2. 第三方节点是可执行代码。来源不明时不要仅因为工作流提示“缺节点”就安装。
