### 接口族清单(14 族)

标准模型 API:`/openapi/v2/{endpoint}`(提交)、`/openapi/v2/query`(查询)、
`/openapi/v2/media/upload/binary`(上传)、`/openapi/v2/price-preview/{endpoint}`
(预估,个人 Key 1014)、`/openapi/v2/assets/*` 与 `assets/groups/*`(素材资产,10 个);
ComfyUI 工作流 API:`/task/openapi/create`、`/task/openapi/upload`、
`/task/openapi/outputs`(deprecated,但含成本与失败归因字段)、
`/task/openapi/status`(deprecated)、`/task/openapi/cancel`、webhook(TASK_END 回调);
AI 应用 API:`/task/openapi/ai-app/run`、`GET /api/webapp/apiCallDemo`(节点参数获取);
LLM API:`https://llm.runninghub.cn(v1)/chat/completions`(OpenAI 兼容,
文档称兼容 Anthropic/Gemini 协议,后两者路径未公开列明)。

**Key 类型与通道**(官方文档 + 实测双重确认):

| Key 类型 | 模型 API | LLM API | AI 应用 API | 工作流 API |
| --- | --- | --- | --- | --- |
| 消费级-会员(个人) | ✗(1014 实测) | ✗ | ✓(实测) | ✓(实测) |
| 企业级-共享 | ✓ | ✓ | ✓ | ✓ |
| 企业级-独占(需购机) | ✗ | ✗ | ✓ | ✓ |

计费通道:AI 应用/工作流消耗平台钱包(币/算力值);第三方模型费
(`thirdPartyConsumeMoney`,元)单独挂账;企业 API 走人民币钱包。
账户余额/账单明细**未发现公开 API**(网页控制台专属)。

## 3. 注册表与验证状态体系

`data/runninghub-api-registry.json` 结构:`meta`(范围/去重/统计/Key 矩阵)
→ `endpoint_families`(14 族,含来源与验证状态)→ `model_capabilities`
(422 条:参数 schema、分辨率/时长枚举、音频、768P/2K 标记、价格条目、
验证状态与注记)→ `pricing_anchors`(MiniMax 原厂价锚点)→ `run_evidence`
(4 条实测证据)→ `gaps`(9 条缺口)。

状态分级严格区分(不把"生成了示例"写成"接口已实测可用"):
**已发现 < 文档已核实 < Schema 已核实 < 示例已生成 < 鉴权已验证 <
真实生成成功 < 费用已核验**。当前全量 422 条为 schema_verified;
H3 三端点标注 `real_run_via_ai_app_2k`(仅 2K 档、仅应用路线);
个人/企业 Key 通道差异为 live_verified。

## 4. 推荐复用方案(方式 A 优先)

**方式 A(默认交付):别人用自己的 RunningHub Key,复用本仓库资料。**
交付物已就绪:
- `examples/python/rh_min_client.py`:零依赖最小客户端,通用传输
  (鉴权/上传/提交/预估/轮询/取消/工作流/AI 应用)与模型参数分离;
- `examples/curl/01–05.sh`:768P 直出、2K 直出、768P→2K 两阶段、
  AI 应用路线、工作流路线的完整 cURL;
- `data/runninghub-api-registry.json` + `model-capabilities.csv`:
  机器可读目录,客户端按注册表拼 payload,禁止硬编码参数;
- 更新方法:`python3 scripts/rh_survey_build_registry.py`(重新拉取
  官方仓库快照再生成)与 `scripts/rh_survey_build_cost_tables.py`。

**方式 B(托管服务,本轮只评估不部署)**:仓库已有可复用底座
(`scripts/rh_capability_api/` 的 manifest 驱动服务:POST /v1/tasks →
202 task_id → GET 轮询,错误码归并,产物转存本地)。可行性判断:
- 技术:底座已实跑,补 OSS 转存、24FPS 前处理、webhook、每用户限额
  即可内测(doc16 估计两三天工程量);
- 条款:**未发现 RunningHub 公开条款禁止企业 API 商用接入**
  (企业级 Key 本身即按量付费的商业产品形态);但"API 可调用"不等于
  "允许无限制转售",正式托管前需与企业渠道书面确认转售/配额条款;
- 风险:托管他人任务会占用本账户并发与余额,需独立企业 Key 与限额,
  本轮不开放账户额度。

## 5. 覆盖边界声明(不得当"全部"吹)

1. **来源**:官方文档站(两站镜像)+ 官方组织仓库 + 本仓库实测;
   未含任何第三方转述作为价格依据(仅作旁证标注)。
2. **版本/时间**:所有快照 2026-09-13 采集;定价文件本身是
   2026-04-29 版;两者时间差已在价格行标注。
3. **动态实例**:AI 应用/工作流是持续新增的社区实例,无公开全量
   枚举接口;交付的是通用 `webappId`/`workflowId` 调用机制 + 已验证
   实例清单,**不声称覆盖平台所有私人/动态实例**。
4. **分页/去重**:模型端点以官方 `endpoint` 字段唯一键去重;一个通用
   提交接口承载 422 个模型端点,HTTP 接口数按 14 族统计,不把每个
   模型算成一个独立 HTTP 接口。
5. **未覆盖**:企业级 Key 专属行为(retainSeconds、price-preview 返回、
   独占队列)、企业后台结算 API、Anthropic/Gemini 协议端点——
   均明确记为缺口而非猜测。

## 6. 缺口汇总(按影响排序)

1. H3 平台侧官方价(高):需企业 Key 的 price-preview 或一条实跑账单。
2. 平台币→人民币官方比例(高):需控制台对账。
3. AI 应用计费公式(中):7 币/309s 与工作流 0.21 币/秒不一致,公式未公开。
4. 官方 OpenAPI 导出缺失(中):接口族以文档+官方仓库代码核对。
5. 新端点(39 个)价格缺失(中)。
6. LLM Anthropic/Gemini 端点路径、账户/账单 API、768P 实际像素、
   平台侧失败退款规则(低)。
