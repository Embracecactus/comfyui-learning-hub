# 剩余实证验收目标（工程一致性已修复）

维护版本：2026-09-21。以 `data/handoff-evidence.json` 中开放的 gaps 为唯一缺口清单；不重写第二套价格，不用历史个人样本替代企业实测，不根据414猜测充值。

1. 用已授权的企业共享Key只读执行 `examples/enterprise-price-plan.json`，保存免费预估、时间与币种；无Key/无权限就留下真实阻塞。价格只更新精确端点与分辨率，不外推H3家族。
2. 先取得一条可信的标准H3 768P源任务、产物及实际最终模型提示词，再按 `04-接入与费用验收.md` 检查源链、核价。仅在明确付费预算授权后完成代表性企业直出及regeneration任务，不自动充值或购买会员。
3. 保留两个阶段的taskId、源视频哈希、最终提示词哈希、终态、media和独立账单项；运行只读对账工具。缺项不是零，父子汇总不能双计；普通超分不冒充生成式再生成。
4. 个人10/15秒附加币、会员/币兑换与独占租金按实际账单补充。不为了统计而付费遍历422个模型，不无限扩展动态社区实例。
5. 回填唯一证据JSON并重建，运行 `python3 scripts/rh_survey_build_cost_tables.py --check` 与 `test_rh_handoff*.py`。工程测试通过与真实费用闭环分别验收。

本目标不要求把未知强行填满。只有相应关闭证据实际取得，才将gap改为closed，并链接到脱敏证据；私人完整原文与签名URL留在忽略目录。
