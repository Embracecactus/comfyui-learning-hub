# 下一阶段开发 /goal(基于已查明事实,含取舍)

> 前提事实:422 个模型端点 schema 已入注册表;14 个接口族已核验;
> H3 2K 链路已实测(¥3.85/5s + 7 币);H3 平台侧官方价、币值比例、
> AI 应用计费公式是仅存的高价值未知数;方式 A 资料已可交付,
> 方式 B 有现成底座但条款未确认。

## 目标

把本轮的"调研成果"变成"可长期维护的接入资产":价格可自动刷新、
企业 Key 通道打通、方式 A 资料包对外可用。

## 做什么(按序,每步有独立验收)

### 第 1 步:企业级-共享 Key 通道核价(最高优先)
- **做什么**:申请/启用企业级-共享 API Key;用 `scripts/runninghub_h3_t2v.py`
  的 price-preview 能力,批量核价 H3 全家族(768P/2K/regeneration)、
  seedance-2.5-token、h3-max-turbo、wan-3.0 等 69 个无价端点
  (422-353),并把 `developer-kit` 换成官方仓库完整版
  (含 examples/tests/mcp-server)。
- **放哪**:脚本入 `scripts/`;结果回写注册表 `pricing` 字段
  (`status: price_preview_verified`)+ 费用报告修订。
- **验收**:69 个缺口端点每条有 price-preview 返回(或明确无预估能力);
  H3 768P/2K 有平台侧官方价;若预算允许,再实测一条 768P 5s +
  一条 regeneration 链路(预估 ¥2.5 + ¥2.75 + 币,先报价后提交,
  沿用 --execute 闸门),把推算行升级为实测行。
- **预算**:核价 0 元(price-preview 不创建任务);实测两条 ≈¥6 + 币,
  需明确授权后执行。

### 第 2 步:币值与账单对账(解锁全部"币"口径)
- **做什么**:在控制台「任务与账单」页核对已发生的全部任务
  (2026-09-09~12,约 10 条)的扣费明细,确定:1 币=¥?
  AI 应用 7 币的计费公式;工作流 0.21 币/秒的档位(24G/Plus)。
- **放哪**:结论写入费用报告 §4;如发现账单 API(抓包控制台),
  记录为非公开接口并在注册表标注"未公开、仅人工"。
- **验收**:费用报告中不再有"币→元未定"占位;两张 CSV 的币列
  补上人民币折算(标明对账日期与适用账户)。

### 第 3 步:方式 A 资料包定稿(对外可交付)
- **做什么**:把 `docs/05-RunningHub-API/` 打包为独立接入包
  (README + 注册表 + rh_min_client.py + cURL + 费用口径说明);
  补 3 个端到端冒烟检查:注册表 schema 校验(参数/枚举非空)、
  客户端 query 冒烟(用已存 taskId)、CSV 数值口径自检
  (每秒×秒数=总价)。
- **放哪**:检查脚本 `scripts/rh_survey_check.py`;文档就地更新。
- **验收**:三个检查全绿;一个外部新人仅凭资料包
  (无本仓库上下文)能按 cURL 04 号示例跑通一次 AI 应用查询。
- **不做**:不写多语言 SDK(单一 Python 客户端 + cURL 足够);
  不做 ComfyUI 节点包装(官方 ComfyUI_RH_OpenAPI 已是 1:1 实现,直接引用)。

### 第 4 步(条件触发):方式 B 托管立项
- **触发条件**:有真实外部用户,且与企业渠道书面确认转售/配额条款。
- **做什么**:基于 `scripts/rh_capability_api/` 服务化,补 OSS 转存、
  webhook、每用户限额(421 退避已实现);独立企业 Key,与本账户隔离。
- **不做**:条款确认前不部署、不开放额度。

## 怎样更新(长期机制)

- **注册表**:`python3 scripts/rh_survey_build_registry.py`
  (重拉官方快照→重建);官方 kit 版本变化时 diff 出新端点并标缺口。
- **价格**:`scripts/rh_survey_build_cost_tables.py` 改数即改表;
  快照价格行每次引用须带日期;企业 Key 就绪后接入 price-preview 实时核价。
- **费用证据**:沿用 run.json + costs.csv 台账结构,新实测任务
  追加进注册表 `run_evidence`,不覆盖旧证据。

## 验收总闸

下一阶段完成的定义:H3 的 768P 与 2K 在 RunningHub 平台侧均有
**非推算**价格(标价或实测);两张费用 CSV 无"缺口"行;
方式 A 资料包通过三项冒烟检查并由非本仓库使用者跑通一次。
