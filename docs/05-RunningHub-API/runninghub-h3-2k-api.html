02 / ENTERPRISE COST

企业版成本与并发调研

以下为 2026-09-17 官方页面与公开接口调研，不是企业 Key 实测。固定公开价与预算演算分开列出，未公开的独占租金不编造。

消费级-会员

可调 AI 应用和工作流，不能直接调用模型 API/LLM。免费、轻享、轻享 Plus、基础版并发 1；基础 Plus/专业版并发 3；专业 Plus/Max 并发 5。运行费为 Lite 0.02、Standard 0.2、Plus 0.4 RH 币/秒，模型节点费另扣钱包。

并发不会摊薄费用

企业共享默认 100 并发，但多任务按各自用量累计：2 条并发 5 秒 H3 为 2 × ¥3.85 = ¥7.70；100 条同时生成为 ¥385.00。官方没有公开“100 并发以内”的额外并发月费；超过 100 的扩容价格页面未披露。

路线选择

只需 H3 文生视频时，企业共享标准模型 API 成本最清晰。需要自定义 ComfyUI 编排时，再选择企业共享 AI 应用/工作流并承担实例秒费；负载长期稳定且不能排队时，才比较独占 GPU 报价。

07 / ERRORS

错误处理与重试纪律

提交任务不是幂等操作。网络中断且响应未知时，先核对控制台和本地记录;禁止通过再次提交来“试试看”。

错误含义 / 证据正确处理
1014个人 Key 无标准模型 API 权限改用本文 AI 应用路线，或申请企业共享 Key
415独占型 API 机器数不足等待独占 GPU 空闲；需要平台排队时使用 usePersonalQueue
416官方定义的账户余额不足查询 accountStatus;充值后重新取得付费授权
421并发队列达到上限；个人 NORMAL Key 双提交时第二个请求已实测被拒应用层串行排队；收到 421 后不要立即重提
802Key 无效或被禁用停止调用并轮换 Key
414曾出现的未文档化 POWER_VALUE 闸门不等同余额不足;若再现，保留时间、webappId、参数和响应交平台支持
动态时长调度纪律

提交前先校验 duration ∈ {5…15} 且为字符串，再按 ¥0.77 × 总秒数预留钱包金额。个人 NORMAL Key 已实测并发上限为 1，所以多任务应在客户端串行排队；421 不立即重提，提交结果不确定时先确认是否已经产生 taskId。
