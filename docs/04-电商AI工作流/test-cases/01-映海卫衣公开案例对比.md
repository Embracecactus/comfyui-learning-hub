# 01｜映海卫衣公开案例：同输入对比测试

这是一组用于验证“参考图驱动商品主图”是否真正生效的固定测试输入。测试对象是映海站公开的“复刻商品主图-卫衣”案例：本地 FLUX.2 Klein 使用同一件 `1977` 黑色卫衣和网站公开参考图生成，再与网站已经公开的成片并排比较。

- [导入专用工作流](../workflows/ecommerce-yinghai-hoodie-comparison-flux2-klein.json)
- [通用工作流与节点说明](../04-参考图驱动商品主图工作流.md)
- [网站观察与技术决策留痕](../reference-site-audit-2026-08-28.md)

本测试没有调用网站生成接口，也没有消耗积分。公开案例图片只下载到本机 ComfyUI 输入目录，不提交到 GitHub。

## 1. 测试边界

网站公开案例实际使用了 `1` 张商品图和 `3` 张对标主图，记录的模型为 `gpt-image-2`、画质为 `2K`、比例为 `9:16`。本地测试只使用其中与网站结果关系最直接的一张白底版式参考图，目的是建立变量更少、可重复的单参考基线。

因此这是一项“相同商品 + 代表性参考”的受控比较，不是网站三参考输入的逐项复刻，也不能仅凭一张本地结果声称模型能力相同。

## 3. 为什么另外准备 9:16 商品输入

官方 FLUX.2 工作流会从图 1 读取宽高，并把它用于输出 latent 和 scheduler。若直接使用 `534 × 642` 商品原图，本地结果不会与网站 `9:16` 画幅一致。

`01b` 文件没有用 AI 重绘商品，只把原图等比缩放后放到白色 `576 × 1024` 画布上：

```bash
convert -size 576x1024 canvas:white \
  \( 01-product-1977-hoodie.png -resize 480x576 \) \
  -gravity north -geometry +0+90 -composite \
  01b-product-1977-hoodie-9x16-canvas.png
```

这样本地首轮输出约为 `576 × 1024`，比例与网站基线一致，同时保留原商品像素作为身份参考。

## 4. 专用工作流做了什么

导入专用 JSON 后，画布会自动选择三张本地图片：

```text
图 1：01b-product-1977-hoodie-9x16-canvas.png
图 2：02-reference-white-chicerro-layout.png
基线：03-site-result-baseline.png（断开，不参与生成）
```

生成提示词把职责拆开：

- 图 1 决定商品身份：黑色颗粒面料、帽子、插肩袖、罗纹袖口和下摆、袋鼠兜及胸前准确的 `1977`。
- 图 2 只提供暖白背景、居中比例、留白和极简服装目录版式。
- 明确禁止复制参考图里的 `CHICERRO`、其他品牌、Logo、水印、口号和文字。
- 只生成一件卫衣，不添加人物、模特、重复服装或无关配件。

工作流固定 seed 为 `2026082802`，输出前缀为：

```text
ComfyUI/output/ecommerce/comparison/yinghai-hoodie-flux2-klein
```

## 5. 第一次运行

1. 重启 `ComfyUI-RTX5060` 实例，或进入画布后按 `R` 刷新模型和输入文件列表。
2. 将 `ecommerce-yinghai-hoodie-comparison-flux2-klein.json` 拖入 ComfyUI。
3. 确认两个生成输入和右侧网站基线都出现预览，不再显示“所需的媒体输入未选择文件”。
4. 确认三个模型下拉框命中 `flux-2-klein-4b-fp8.safetensors`、`qwen_3_4b.safetensors`、`flux2-vae.safetensors`。
5. 保持 4 步、CFG `1`、batch `1` 和固定 seed，不要先改提示词。
6. 点击“运行”，等待本地结果保存。
7. 将本地结果与右侧 `网站公开结果基线` 节点逐项比较，并保存运行耗时、显存峰值和输出文件名。

右侧基线节点没有连接到采样器。它只是一把视觉尺子，不会泄漏到本地生成链路。

## 6. 验收表

| 检查项 | 通过标准 | 常见失败 |
|---|---|---|
| 商品身份 | 单件黑色连帽卫衣，整体轮廓接近商品图 | 变成衬衫、外套或出现第二件衣服 |
| 胸前数字 | 清楚且仍为 `1977` | 数字缺失、变形或改成其他数字 |
| 结构 | 帽子、插肩袖、袋鼠兜、袖口和下摆保留 | 口袋消失、袖型改变、结构粘连 |
| 材质与颜色 | 黑色颗粒/杂色面料基本保留 | 变成纯色、浅色或光滑皮革 |
| 版式借鉴 | 暖白背景、居中、留白充分、9:16 商业目录感 | 仍像原始上传图，或背景过于复杂 |
| 品牌安全 | 没有 `CHICERRO` 或其他竞品文字/Logo | 复制参考图品牌或生成乱码文字 |
| 画面完整性 | 只有一件商品，接触阴影自然 | 多商品、人物、配件、悬浮或畸形阴影 |

首轮通过的含义是：本地双参考链路确实同时利用了商品身份与参考版式。它不代表 `1977` 已达到印刷级文字保真，也不代表本地模型整体追平网站服务。
