# 01｜电商商品场景图：AI 生成背景，原商品无损合成

本章开始搭建一套类似[赢海 AIGC 站](https://yinghai.xin/)公开功能方向的本地电商素材工作流。该网站公开描述了商品主图、详情页、模特穿搭、场景图和带货视频等能力；其服务端模型与内部编排没有公开，因此本系列复现的是**可观察的产品功能和输入输出**，不是声称复制其私有实现。

这是独立电商项目的第一条工作流，只负责把透明商品图制作成可交付的商品场景图：

```text
透明底商品 PNG
   ├→ 读取透明通道 → 商品遮罩 → 柔和投影 ─┐
   │                                      ├→ 原商品像素合成 → 商品场景图
文本提示词 → SDXL → 无商品的电商背景 ─────┘
```

- [下载本章工作流 JSON](workflows/ecommerce-product-scene-sdxl.json)
- [SDXL Base 官方模型页](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0)

## 1. 导入 JSON 后先解决两个验证错误

第一次导入配套 JSON 时，ComfyUI 很可能显示：

```text
检测到错误
请在运行工作流前解决
2 个节点 — 2 个错误

缺失模型：sd_xl_base_1.0.safetensors（checkpoints）
缺少输入：上传 1:1 透明底商品 PNG - image
```

这是工作流的两个外部输入尚未准备好，不是节点损坏，也不需要安装自定义节点。

| 错误 | 原因 | 解决方法 |
|---|---|---|
| 缺失模型 | 本机 `models/checkpoints` 中没有模板指定的 SDXL 权重 | 按 [3.1 节](#31-sdxl-模型)下载模型，刷新后在 `CheckpointLoaderSimple` 中重新选择 |
| 缺少媒体输入 | JSON 只能保存文件名占位，不能携带你的商品素材 | 打开“上传 1:1 透明底商品 PNG”节点，选择自己的透明 PNG |

### 1.1 解决“缺失模型”

模型下载并校验完成后，应位于 Desktop 共享模型目录：

```text
%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared\models\checkpoints\sd_xl_base_1.0.safetensors
```

回到 ComfyUI 后：

1. 按 `R` 刷新节点和模型列表。
2. 打开 `CheckpointLoaderSimple`。
3. 选择 `sd_xl_base_1.0.safetensors`。
4. 下拉列表仍没有该文件时，完全重启当前 ComfyUI 实例，并确认没有误放到另一个便携版的 `models/checkpoints`。

不要把尚未完成的 `.download` 文件直接改成 `.safetensors`，也不要把模型放进 `diffusion_models`；`CheckpointLoaderSimple` 查找的是 `checkpoints` 目录。

### 1.2 解决“缺少输入”

打开标题为“上传 1:1 透明底商品 PNG”的 `LoadImage` 节点，点击上传/选择图片区域，然后选择商品文件。

图片至少应满足：

- 文件格式为 PNG，不能是 JPG。
- 确实包含 alpha 透明通道；白色背景和画在图片里的棋盘格都不算透明。
- 画布推荐为 1:1，商品居中并留有透明边距。

选中图片后，节点内应出现商品预览，“缺少输入”随即消失。如果预览正常但后面运行只得到原图、看不到 AI 背景，通常是 PNG 没有真实透明通道，参见[常见问题](#9-常见问题)。

### 1.3 可以运行的验收条件

点击运行前确认：

- 错误计数从 `2` 变为 `0`。
- `CheckpointLoaderSimple` 显示完整的 SDXL 文件名，不是 `null` 或 `undefined`。
- `LoadImage` 中能看到商品和透明背景预览。
- 没有“缺失节点”提示；本工作流的 16 个节点全部属于 ComfyUI Core。

## 2. 为什么不让 AI 重新绘制商品

电商图最怕下面几类错误：

- 包装文字变成乱码。
- Logo、瓶盖、接口或商品结构改变。
- 颜色、材质和 SKU 与真实商品不一致。
- 同一批图片中的商品外观漂移。

所以第一版采用“**AI 只画背景，商品使用原始像素覆盖**”的方案。它的优点是商品本体、标签和 Logo 保持不变，适合小白理解遮罩和合成；不足是模型不会真正重算商品表面的环境反射，复杂场景下仍可能有“贴上去”的感觉。本章用柔和接触阴影减轻这个问题，后续再增加光色匹配和局部融合。

## 3. 需要准备什么

### 3.1 SDXL 模型

下载官方 `sd_xl_base_1.0.safetensors`，放入：

```text
ComfyUI/models/checkpoints/sd_xl_base_1.0.safetensors
```

官方文件约 6.94 GB，SHA256 为：

```text
31e35c80fc4829d14f90153f4c74cd59c90b779f6afe05a74cd6120b893f7e5b
```

国内网络无法直连 Hugging Face 时，可以使用下面的社区镜像和断点续传方法：

```bat
set "MODEL_ROOT=%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared\models"
set "SDXL_FILE=sd_xl_base_1.0.safetensors"
set "SDXL_BASE=https://hf-mirror.com/stabilityai/stable-diffusion-xl-base-1.0/resolve/main"
cd /d "%MODEL_ROOT%\checkpoints"
curl.exe -L --fail --retry 20 --retry-all-errors --retry-delay 5 -C - -o "%SDXL_FILE%.download" "%SDXL_BASE%/%SDXL_FILE%"
certutil -hashfile "%SDXL_FILE%.download" SHA256
move /Y "%SDXL_FILE%.download" "%SDXL_FILE%"
```

必须先确认 SHA256 完全一致，再执行 `move`。`hf-mirror.com` 是社区镜像，不是 Hugging Face 官方站点；模型来源、哈希和许可证以官方模型页为准。

### 3.2 一张真正带透明通道的商品 PNG

建议输入：

- PNG 格式，背景透明，不是“看起来像棋盘格”的普通 JPG。
- 画布比例为 `1:1`，推荐 1024 × 1024 或 768 × 768。
- 商品在画布中水平居中，占画面高度约 55%～75%。
- 商品底部保留少量透明空间，便于放置接触阴影。
- 边缘干净，没有残留白边和旧背景。

本章 JSON 中的 `product-transparent.png` 只是占位文件名。导入后必须在 `LoadImage` 节点重新选择自己的商品 PNG。

暂时没有素材时，可下载并上传项目内的[无品牌琥珀精华瓶测试 PNG](assets/test-products/amber-serum-transparent.png)。文件为 1254 × 1254 RGBA，透明区域的 alpha 范围已经验证为 0～1，适合直接测试 `LoadImage → InvertMask` 支路。

如果手里只有普通带背景的商品照片，先完成[第二章自动抠图与白底主图](02-自动抠图与白底主图工作流.md)，再把它保存的透明 PNG 上传到本章。

## 4. 配置选择

| 显存 | 建议尺寸 | 说明 |
|---:|---:|---|
| 6 GB 或更低 | 512 × 512 | 可以学习流程，细节有限；必要时使用低显存模式 |
| 8 GB | 768 × 768 | 本章默认值，batch 保持 1 |
| 12 GB 及以上 | 1024 × 1024 | 更接近 SDXL 原生分辨率，生成更慢 |

改变尺寸时必须同时修改：

1. `EmptyLatentImage` 的 width 和 height。
2. 纯黑 `EmptyImage` 的 width 和 height。

两处尺寸不同会让阴影合成错位。输入商品采用 `resize_source=true` 自动适配背景画布，因此商品 PNG 也应保持相同比例，避免拉伸。

## 5. 从空白画布搭建

### 第一步：生成“不含商品”的背景

添加 6 个节点：

```text
CheckpointLoaderSimple
CLIPTextEncode（正向）
CLIPTextEncode（负向）
EmptyLatentImage
KSampler
VAEDecode
```

设置 `CheckpointLoaderSimple`：

```text
sd_xl_base_1.0.safetensors
```

正向提示词：

```text
premium ecommerce product photography background, warm beige studio,
clean stone tabletop, soft window light from upper left,
realistic contact shadow area, subtle depth of field,
empty center foreground for product placement,
high-end commercial photography, no product, no text, no logo
```

负向提示词：

```text
product, bottle, box, package, text, letters, logo, watermark,
people, hands, clutter, duplicate objects, distorted geometry,
low quality, blurry, oversaturated
```

正向词故意要求 `empty center foreground`，负向词故意禁止 `product`。因为商品稍后使用原始 PNG 合成，背景模型不应该提前生成一个假商品。

`EmptyLatentImage` 设置：

```text
width  = 768
height = 768
batch  = 1
```

`KSampler` 设置：

| 参数 | 默认值 |
|---|---:|
| seed | `123456789` |
| control_after_generate | `fixed` |
| steps | `24` |
| cfg | `6.5` |
| sampler | `dpmpp_2m` |
| scheduler | `karras` |
| denoise | `1.0` |

连接方式与普通文生图相同：

```text
CheckpointLoaderSimple.MODEL → KSampler.model
CheckpointLoaderSimple.CLIP  → 两个 CLIPTextEncode.clip
正向 CONDITIONING            → KSampler.positive
负向 CONDITIONING            → KSampler.negative
EmptyLatentImage.LATENT       → KSampler.latent_image
KSampler.LATENT               → VAEDecode.samples
CheckpointLoaderSimple.VAE    → VAEDecode.vae
```

到这里，`VAEDecode.IMAGE` 应该是一张中央留空的电商摄影背景。

### 第二步：从透明通道得到商品遮罩

添加：

```text
LoadImage
InvertMask
```

连接：

```text
LoadImage.MASK → InvertMask.mask
```

这里必须理解 ComfyUI 的遮罩方向：

- `LoadImage.MASK` 对带 alpha 的 PNG 输出 `1 - alpha`。
- 透明背景为白色值 1，实体商品为黑色值 0。
- `ImageCompositeMasked` 却需要“要覆盖的商品区域为白色”。
- 所以必须经过 `InvertMask`，得到商品白、背景黑的遮罩。

如果输入图片没有透明通道，`LoadImage` 会给出空遮罩；反转后可能变成整张白色，最终会让原图覆盖整个 AI 背景。这是本工作流最常见的输入错误。

### 第三步：把商品轮廓变成柔和投影

添加：

```text
MaskToImage
ImageBlur
ImageToMask
EmptyImage
ImageCompositeMasked（阴影合成）
```

连接遮罩处理链：

```text
InvertMask.MASK → MaskToImage.mask
MaskToImage.IMAGE → ImageBlur.image
ImageBlur.IMAGE → ImageToMask.image
ImageToMask.MASK → 阴影合成.mask
```

参数：

- `ImageBlur.blur_radius = 21`
- `ImageBlur.sigma = 3.0`
- `ImageToMask.channel = red`
- `EmptyImage = 768 × 768`、batch `1`、颜色 `#000000`

然后连接阴影：

```text
VAEDecode.IMAGE → 阴影合成.destination
EmptyImage.IMAGE → 阴影合成.source
ImageToMask.MASK → 阴影合成.mask
```

阴影合成节点设置：

```text
x = 0
y = 12
resize_source = false
```

它会按照模糊后的商品轮廓，把黑色图层向下偏移 12 像素合成到背景。商品中心位置虽然也会变黑，但下一步会用原商品完全覆盖；最终能看到的主要是边缘和底部柔和阴影。

### 第四步：覆盖原始商品像素

再添加一个 `ImageCompositeMasked`，命名为“最后覆盖原始商品像素”。

连接：

```text
阴影合成.IMAGE → 最终合成.destination
LoadImage.IMAGE → 最终合成.source
InvertMask.MASK → 最终合成.mask
```

设置：

```text
x = 0
y = 0
resize_source = true
```

这是保持商品真实性的关键节点：背景和阴影可以由 AI 生成，最后出现的商品本体仍来自上传 PNG 的原始 RGB 像素。

### 第五步：预览和保存

添加 `PreviewImage` 和 `SaveImage`：

```text
最终合成.IMAGE → PreviewImage.images
最终合成.IMAGE → SaveImage.images
```

保存前缀：

```text
ecommerce/product-scene
```

生成结果位于：

```text
ComfyUI/output/ecommerce/
```

## 6. 16 个节点功能速查

| # | 节点 | 作用 |
|---:|---|---|
| 1 | `CheckpointLoaderSimple` | 一次加载 SDXL 的 MODEL、CLIP 和 VAE |
| 2 | 正向 `CLIPTextEncode` | 编码希望出现的场景、材质和光线 |
| 3 | 负向 `CLIPTextEncode` | 避免背景提前生成商品、人物和文字 |
| 4 | `EmptyLatentImage` | 决定背景分辨率和生成数量 |
| 5 | `KSampler` | 对空潜空间执行扩散生成 |
| 6 | `VAEDecode` | 把背景潜空间还原为像素图片 |
| 7 | `LoadImage` | 读取透明商品 PNG，同时输出反向 alpha mask |
| 8 | `InvertMask` | 把遮罩改为商品白、背景黑 |
| 9 | `MaskToImage` | 为图像模糊节点把 MASK 临时转为 IMAGE |
| 10 | `ImageBlur` | 把硬商品轮廓变成柔和阴影轮廓 |
| 11 | `ImageToMask` | 从模糊图像的红色通道恢复 MASK |
| 12 | `EmptyImage` | 创建用于投影的纯黑像素层 |
| 13 | 阴影 `ImageCompositeMasked` | 把黑色柔和轮廓向下合成到背景 |
| 14 | 商品 `ImageCompositeMasked` | 用原始商品像素覆盖背景和阴影 |
| 15 | `PreviewImage` | 在界面中快速检查效果 |
| 16 | `SaveImage` | 保存场景图并保留工作流元数据 |

## 9. 常见问题

### 最终只看到原商品图，看不到背景

输入文件没有透明 alpha，或者透明区域其实已经被填成白色。用图片编辑软件检查图层透明度，再导出 PNG。

### 商品被拉宽或压扁

`resize_source=true` 会让 source 适配 destination。背景是 1:1 时，商品 PNG 画布也必须为 1:1；不要直接上传细长的裁边 PNG。

### 背景里又出现一个假商品

加强正向词中的 `empty center foreground`，并在负向词加入实际品类，例如 `cosmetic bottle`、`shoe` 或 `handbag`。这不会影响最后覆盖的真实商品。

### 阴影太黑

先把 `ImageBlur.sigma` 从 3 提高到 5，扩大过渡；也可以把 `y` 从 12 降到 6。当前纯核心节点版本没有单独的阴影透明度滑块，后续可增加图像混合节点实现强度控制。

### 阴影方向和背景光线矛盾

当前阴影是由商品轮廓机械生成的，不理解背景光源。让背景提示词固定为“左上方柔光”，并保持阴影轻微；复杂硬光场景需要后续局部重绘或光照协调模型。

### 爆显存

把 `EmptyLatentImage` 和 `EmptyImage` 同时改为 640 × 640 或 512 × 512，batch 保持 1。SDXL Base 可以单独运行，不要求同时下载 Refiner。

## 10. 当前版本的边界与下一步

这版已经实现：

- AI 背景生成。
- 商品透明通道解析。
- 接触阴影模拟。
- 原始商品像素保真。
- 商品场景图预览和独立保存。

还没有实现：

- 自动抠图。
- 商品受环境光影响的真实重打光。
- 多 SKU 批量循环。
- 模特试穿。
- 中文详情页排版。
- 参考爆款视频的镜头拆分与节奏复刻。

这些能力会按[电商工作流学习路线](README.md)逐步增加。技术上能生成不等于素材可以直接商用；还要检查模型许可证、商品商标、人物肖像、输入素材版权和发布平台的 AI 内容标注要求。
