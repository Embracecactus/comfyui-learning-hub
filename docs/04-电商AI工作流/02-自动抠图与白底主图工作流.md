# 02｜普通商品照片自动抠图，并生成透明底与白底主图

第一阶段已经验证了“AI 背景 + 原商品像素合成”。但它要求输入已经抠好的透明 PNG，这不符合大多数电商素材平台“上传普通商品照片即可处理”的入口体验。

本章补齐这个入口：使用 ComfyUI Core 原生支持的 BiRefNet，从普通商品照片中识别商品前景，一次运行同时得到透明底 PNG 和纯白底商品主图。

```text
普通商品照片
  └→ BiRefNet → 商品前景遮罩 ─┬→ 反转遮罩 → 写入 Alpha → 透明底 PNG
                              └→ 原图商品 + 同尺寸纯白图 → 白底商品主图
```

- [下载本章工作流 JSON](workflows/ecommerce-auto-cutout-white-background-birefnet.json)
- [ComfyUI 官方 BiRefNet 教程](https://docs.comfy.org/tutorials/utility/remove-background-birefnet)
- [Comfy-Org BiRefNet 模型文件](https://huggingface.co/Comfy-Org/BiRefNet/blob/main/background_removal/birefnet.safetensors)

这条工作流与[赢海 AIGC 站](https://yinghai.xin/)的商品主图/白底图入口属于相似的功能类别，但没有使用或推断其未公开的服务端实现。

## 1. 这一步通过后能得到什么

一次运行产生两类文件：

| 输出 | 保存目录前缀 | 用途 |
|---|---|---|
| 透明底 RGBA PNG | `output/ecommerce/cutout` | 继续送入第一章场景图、海报合成或版式设计 |
| 纯白底商品图 | `output/ecommerce/white-background` | 电商白底主图、抠图质量检查和商品素材归档 |

透明结果不是“画上去的棋盘格”，而是写入了真实 alpha 通道。白底结果也不是 AI 重画商品，只是把原始商品像素按照遮罩覆盖到纯白画布上，所以标签、Logo 和商品结构不会被生成模型改写。

## 2. 运行前准备 BiRefNet 模型

本工作流只使用 ComfyUI Core 节点，不需要安装第三方自定义节点，但需要一个抠图模型：

```text
ComfyUI/models/background_removal/birefnet.safetensors
```

官方文件大小为 `444,473,596` 字节，约 424 MiB（文件页面通常显示约 444 MB），SHA256：

```text
9ab37426bf4de0567af6b5d21b16151357149139362e6e8992021b8ce356a154
```

### 2.1 Windows Desktop 国内网络手动下载

完全退出正在运行的工作流不是必需的，但下载完成后要刷新模型列表或重启实例。打开 `cmd.exe`，逐行执行：

```bat
set "MODEL_ROOT=%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared\models"
set "BIREFNET_FILE=birefnet.safetensors"
set "BIREFNET_URL=https://hf-mirror.com/Comfy-Org/BiRefNet/resolve/main/background_removal/birefnet.safetensors"
if not exist "%MODEL_ROOT%\background_removal" mkdir "%MODEL_ROOT%\background_removal"
cd /d "%MODEL_ROOT%\background_removal"
curl.exe -L --fail --retry 20 --retry-all-errors --retry-delay 5 -C - -o "%BIREFNET_FILE%.download" "%BIREFNET_URL%"
certutil -hashfile "%BIREFNET_FILE%.download" SHA256
move /Y "%BIREFNET_FILE%.download" "%BIREFNET_FILE%"
```

先确认 `certutil` 输出与上面的 SHA256 完全一致，再执行最后一行 `move`。`hf-mirror.com` 是社区镜像；来源、哈希和许可证仍应以官方模型页为准。

下载完成后，在 ComfyUI 中按 `R` 刷新。如果“加载 BiRefNet 抠图模型”节点仍看不到 `birefnet.safetensors`，完全重启当前 Desktop 实例，并检查文件有没有误放到 `checkpoints` 或某个便携版目录。

## 3. 输入照片怎么选

第一次测试建议使用满足以下条件的普通商品照片：

- 画面中只有一个主要商品，商品没有被手或其他物体大面积遮挡。
- 商品与背景存在颜色或明暗差异。
- 图片清晰，没有严重运动模糊，商品边缘没有被裁掉。
- JPG、PNG 都可以；输入不要求事先带透明通道。
- 玻璃、薄纱、烟雾、毛发、镂空、强反光金属属于高难度边缘，应在遮罩预览中放大检查。

如果输入本来就是透明 PNG，工作流仍能运行，但这不能有效验证自动抠图质量。应另选一张真实带背景的商品照片验收本章。

## 4. 导入后先看这两个错误

导入 JSON 时可能显示：

```text
缺失模型：birefnet.safetensors（background_removal）
缺少输入：上传普通商品照片（允许有背景）- image
```

分别按下面处理：

1. 将模型放到 `models/background_removal`，刷新并在加载节点重新选择。
2. 打开 `LoadImage` 节点，上传一张普通商品照片。

如果显示 `LoadBackgroundRemovalModel` 或 `RemoveBackground` 为缺失节点，不要到 Manager 搜索同名插件。这两个是新版 ComfyUI Core 节点，应先在 Desktop 实例管理页执行更新，然后重启实例。

## 5. 从空白画布搭建 14 个节点

### 第一步：上传普通商品照片

添加：

```text
LoadImage
```

`IMAGE` 输出会同时送往抠图、透明图合成、尺寸读取和白底合成。节点的 `MASK` 输出在本章不用，因为普通 JPG 没有可用 alpha；真正的商品遮罩由 BiRefNet 预测。

### 第二步：加载模型并识别商品前景

添加：

```text
LoadBackgroundRemovalModel
RemoveBackground
```

选择：

```text
birefnet.safetensors
```

连接：

```text
LoadImage.IMAGE → RemoveBackground.image
LoadBackgroundRemovalModel.bg_model → RemoveBackground.bg_removal_model
```

`LoadBackgroundRemovalModel` 只负责从磁盘读取权重；`RemoveBackground` 才会分析输入图片，并输出一个 `MASK`。这个 MASK 的语义是：

- 白色（值接近 1）：模型判断为商品前景。
- 黑色（值接近 0）：模型判断为背景。
- 灰色：半透明或柔和边缘。

### 第三步：用 GrowMask 微调边缘

添加：

```text
GrowMask
MaskPreview
```

连接：

```text
RemoveBackground.mask → GrowMask.mask
GrowMask.MASK → MaskPreview.mask
```

默认参数：

```text
expand   = 0
tapered  = true
```

`GrowMask` 在默认 `0` 时不改变轮廓，但把后续可能需要的边缘修正位置预留出来：

| 现象 | 建议尝试 | 风险 |
|---|---:|---|
| 商品外圈残留旧背景或白边 | `expand = -1`，必要时 `-2` | 数值过小会吃掉细边、文字或透明材质 |
| 商品边缘被切掉 | `expand = 1`，必要时 `2` | 数值过大会带回旧背景 |
| 遮罩已经干净 | 保持 `0` | 不做无意义修正 |

先看 `MaskPreview`：主体应为白色，背景应为黑色。若主体和背景识别完全相反，不要立刻乱加反转节点，应先确认看到的是哪一个支路；本章的透明图支路本来就还有一次方向转换。

### 第四步：输出真实透明底 PNG

添加：

```text
InvertMask
JoinImageWithAlpha
PreviewImage
SaveImage
```

连接：

```text
GrowMask.MASK → InvertMask.mask
LoadImage.IMAGE → JoinImageWithAlpha.image
InvertMask.MASK → JoinImageWithAlpha.alpha
JoinImageWithAlpha.IMAGE → PreviewImage.images
JoinImageWithAlpha.IMAGE → SaveImage.images
```

这里的 `InvertMask` 不是重复操作。原因是 ComfyUI 的合成遮罩和 alpha 接口方向不同：

- `ImageCompositeMasked` 使用“白色区域需要贴入”的前景遮罩。
- `JoinImageWithAlpha` 内部按 ComfyUI MASK 语义处理，值 1 代表透明区域。
- BiRefNet 输出的却是“前景白、背景黑”。

因此，透明支路必须先反转为“背景白、商品黑”，再交给 `JoinImageWithAlpha`。反转少一次会得到“商品透明、背景保留”的错误结果。

保存前缀设置为：

```text
ecommerce/cutout
```

### 第五步：创建同尺寸纯白背景

添加：

```text
GetImageSize
EmptyImage
```

连接：

```text
LoadImage.IMAGE → GetImageSize.image
GetImageSize.width  → EmptyImage.width
GetImageSize.height → EmptyImage.height
```

`EmptyImage` 设置：

```text
batch_size = 1
color      = #FFFFFF（十进制 16777215）
```

动态读取宽高的意义是白色画布永远和输入照片一致，不会因为写死 1024 × 1024 而拉伸商品或发生遮罩错位。本工作流按单张图片处理，因此 batch 保持 1。

### 第六步：把原商品像素合成到白底

添加：

```text
ImageCompositeMasked
PreviewImage
SaveImage
```

连接：

```text
EmptyImage.IMAGE → ImageCompositeMasked.destination
LoadImage.IMAGE  → ImageCompositeMasked.source
GrowMask.MASK    → ImageCompositeMasked.mask
ImageCompositeMasked.IMAGE → PreviewImage.images
ImageCompositeMasked.IMAGE → SaveImage.images
```

合成参数：

```text
x             = 0
y             = 0
resize_source = false
```

白底支路必须使用没有反转的商品前景遮罩：白色商品区域从原图贴入，黑色背景区域继续显示纯白画布。因为两张图尺寸已经动态保持一致，所以不需要缩放 source。

保存前缀设置为：

```text
ecommerce/white-background
```

## 6. 完整连线清单

配套 JSON 共 14 个节点、17 条连线：

| # | 输出 | 输入 | 作用 |
|---:|---|---|---|
| 1 | `LoadImage.IMAGE` | `RemoveBackground.image` | 提交商品照片给 BiRefNet |
| 2 | `LoadBackgroundRemovalModel.bg_model` | `RemoveBackground.bg_removal_model` | 提供抠图模型 |
| 3 | `RemoveBackground.mask` | `GrowMask.mask` | 送入边缘调整 |
| 4 | `GrowMask.MASK` | `MaskPreview.mask` | 检查商品白、背景黑 |
| 5 | `GrowMask.MASK` | `InvertMask.mask` | 生成透明度方向遮罩 |
| 6 | `LoadImage.IMAGE` | `JoinImageWithAlpha.image` | 保留原商品 RGB 像素 |
| 7 | `InvertMask.MASK` | `JoinImageWithAlpha.alpha` | 写入真实透明通道 |
| 8–9 | `JoinImageWithAlpha.IMAGE` | 透明图预览、保存 | 输出透明 PNG |
| 10 | `LoadImage.IMAGE` | `GetImageSize.image` | 读取输入尺寸 |
| 11–12 | `GetImageSize.width/height` | `EmptyImage.width/height` | 创建同尺寸白底 |
| 13 | `EmptyImage.IMAGE` | `ImageCompositeMasked.destination` | 设置纯白底图 |
| 14 | `LoadImage.IMAGE` | `ImageCompositeMasked.source` | 使用原商品像素 |
| 15 | `GrowMask.MASK` | `ImageCompositeMasked.mask` | 只贴入商品区域 |
| 16–17 | `ImageCompositeMasked.IMAGE` | 白底图预览、保存 | 输出白底商品图 |

## 7. 验收标准

一次运行结束后，依次检查：

1. `MaskPreview` 中商品白、背景黑，没有明显漏块。
2. 透明图预览只剩商品；下载 PNG 后在不同颜色背景上查看，确认不是假棋盘格。
3. 白底图背景为纯白，原来的桌面、墙面和阴影已经移除。
4. 商品标签、Logo、瓶盖等仍来自原图，没有被 AI 重画。
5. 放大边缘后没有明显旧背景色边；若有，先把 `GrowMask.expand` 从 `0` 改为 `-1` 比较。

这五项通过，就可以把透明输出直接作为[第一章商品场景图](01-商品场景图工作流.md)的新输入。两个 JSON 仍保持独立，便于逐步学习、单独排错和释放显存。

## 8. 常见问题

### 8.1 报错 `LoadBackgroundRemovalModel` 不存在

这是 ComfyUI Core 版本较旧，不代表应该安装同名第三方节点。先更新 Desktop 中的当前实例，重启后再导入工作流。

### 8.2 模型已经下载，但节点下拉框没有文件

确认完整路径是：

```text
%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared\models\background_removal\birefnet.safetensors
```

不是 `models/checkpoints`，也不是实例目录下另一个未共享的 `models`。随后按 `R` 或重启实例。

### 8.3 透明图只剩背景，商品反而透明

透明支路的遮罩方向错了。恢复标准连线：

```text
GrowMask → InvertMask → JoinImageWithAlpha.alpha
```

白底支路则不经过 `InvertMask`。

### 8.4 白底图仍残留一圈旧背景

先放大 `MaskPreview` 区分是遮罩边缘残留还是原商品自身的反光。遮罩残留可把 `GrowMask.expand` 调为 `-1`；透明玻璃、镂空和强反光商品如果仍不理想，需要后续增加专用精修支路，不能一味继续缩小遮罩。

### 8.5 多个商品只抠出其中一个

BiRefNet 更适合主体明确的单商品照片。先裁剪图片、减少背景干扰，或把多个商品作为一个整体拍摄；需要逐个商品独立输出时，应分别处理。

### 8.6 显存是否够用

BiRefNet 模型远小于 SDXL，而且本章不加载扩散模型。常见 6–8 GB 显存机器可先按原图运行；超高分辨率照片仍会增加内存和处理时间，首次测试可先缩到 1024～2048 像素长边。
